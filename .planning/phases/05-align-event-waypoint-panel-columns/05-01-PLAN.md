<threat_model>
### Assets
- Waypoint readability: Event rows must show the correct video timeline range and event type.
- Annotation compatibility: existing `interacting_object` JSON must remain round-trippable.
- Selection integrity: existing waypoint selection and deletion must still act on the tagged Event Waypoint.

### Trust Boundaries
- Imported JSON can contain timestamps and interacting-object values that differ from the desired UI values.
- Existing mouse handlers assume an editable Event-list subitem index.

### Threats
- T-05-01 (medium): A stale index-based editor mutates hidden metadata after the column is removed.
- T-05-02 (medium): JSON/subtitle timestamp leakage makes Event Entry/Exit disagree with Person/Vehicle timing.
- T-05-03 (low): Removing the visible field accidentally removes JSON persistence.

### Mitigations
- Remove or inert the Event-specific inline editing triggers while retaining ListView item tags and selection handlers.
- Generate all Event row times directly from `WaypointMarker.EntryTime` and `ExitTime`.
- Do not change `WaypointMarker.InteractingObject` or JSON import/export code; cover row-display separation in the harness.
</threat_model>
