    - D-01/D-02: for a valid selected event box at frame F, plan changes only frames F+1 through the resolved waypoint ExitFrame; no earlier frame is touched.
    - D-03: a frame in the supplied `manuallyAdjustedFrames[TrackingIdentityHelper.GetIdentityKey(source)]` set is omitted from updates and creation.

    - Security: when `ResolveActiveScope` is null, or source is not an event box, return an empty plan; an EventId-only match must never select a target.

  </behavior>

Resolve scope first through `EventWaypointUpdateHelper.ResolveActiveScope`; then inspect every frame from source+1 through exit, including deleted boxes in frame lookup. Return explicit update/create records based on stable box references so the UI layer can apply them and capture atomic undo history. Copy source identity and relevant annotation fields only for a newly derived event box. Preserve the current `manuallyAdjustedFrames` in-memory representation and do not add serialization fields or invoke tracking/changed-object paths reserved for Phase 7.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Manual event edit → propagation planner | A mutable UI-selected box must be constrained to its one resolved event waypoint. |
| Existing box state → derived-box decision | A deletion tombstone and a later manual correction must not be mistaken for a missing derived box. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Tampering | `EventWaypointBoxPropagationHelper.PlanPropagation` | mitigate | Call `ResolveActiveScope` first; return an empty result for null/ambiguous scope and use its instance-first membership rather than EventId-only filtering. |
| T-06-02 | Tampering | Per-frame target lookup | mitigate | Include deleted same-instance boxes in lookup and skip them, so an `IsDeleted` tombstone blocks replacement creation. |
| T-06-03 | Tampering | Manual-frame precedence | mitigate | Use the existing `event_instance_{EventInstanceId}` identity key and skip protected later frames. |
| T-06-SC | Tampering | Package installs | accept | No package-manager installation is planned; the existing .NET project and console harness are used. |
</threat_model>
