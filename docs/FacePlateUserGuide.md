# 얼굴·번호판 라벨링 안내

## 얼굴 라벨

1. 클래스에서 `Person`을 선택합니다.
2. 인물의 전신 영역에서 **좌클릭 드래그**하여 전신 박스를 만듭니다.
3. 얼굴 식별이 가능한 경우 얼굴 영역에서 **우클릭 드래그**하여 얼굴 박스를 만듭니다.
4. 얼굴이 작거나 뒤통수만 보이는 경우에는 전신 박스만 생성합니다.

얼굴 박스는 전신 박스와 별도로 저장되지만, 같은 인물에 연결되어 관리됩니다. 저장 후 다시 열어도 전신과 얼굴의 연결 관계가 유지됩니다.

## 번호판 라벨

1. 클래스에서 `Vehicle`을 선택합니다.
2. 차량 전체 영역에서 **좌클릭 드래그**하여 차량 박스를 만듭니다.
3. 차량 박스가 먼저 존재하는 상태에서 번호판 영역을 **우클릭 드래그**하여 번호판 박스를 만듭니다.

번호판은 연결된 차량의 하위 박스로 관리됩니다. 번호판 박스만 추가하거나 수정해도 차량 박스는 사라지거나 변경되지 않습니다.

## 추적 및 주의사항

- 얼굴과 번호판은 각각 독립된 박스입니다.
- 번호판은 연결할 차량 박스가 같은 프레임에 있어야 생성할 수 있습니다.
- 관성 추적 시에는 추적하려는 얼굴 또는 번호판 박스를 직접 선택합니다.
- 번호판 추적은 차량 크기 변화에 종속되지 않고, 번호판 자체의 위치와 크기를 기준으로 처리됩니다.
- 저장 시 일반 annotation과 함께 연결 정보가 저장되며, 기존 JSON 구조와도 호환됩니다.
